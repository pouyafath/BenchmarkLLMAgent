## File Guide

- `TSE_PAPER_READINESS_ASSESSMENT.md`
  - overall judgment, paper framing, contribution boundaries, stage model, methodology summary, blockers
- `TSE_PAPER_OUTLINE.md`
  - title candidates, abstract skeleton, section plan, artifact mapping
- `EXPERIMENT_ARTIFACT_MAP.md`
  - authoritative artifacts by stage, mutable versus immutable boundary
- `RESULTS_AUTHORITY_MATRIX.md`
  - accepted, provisional, and superseded numeric results
- `THREATS_TO_VALIDITY.md`
  - internal, construct, external, and conclusion validity risks
- `OPEN_QUESTIONS_FOR_TSE_DRAFT.md`
  - unresolved scope, methods, and experiment decisions
- `FIGURE_TABLE_CANDIDATES.md`
  - candidate visuals and tables for the draft
- `CLAIM_EVIDENCE_TRACEABILITY.md`
  - claim-by-claim evidence boundary
